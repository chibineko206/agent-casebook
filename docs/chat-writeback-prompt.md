# チャット / Cowork / リポ外の Code からの書き戻し用プロンプト

このリポの外で相談したとき、記録を agent-casebook に持ち帰るための定型文。
（背景はマニュアル「モードの使い分け」「ケース別の対処 > 管理リポ外での相談をここに移行する」）

## チャットの場合

相談の終わりに、次をそのまま貼る。

```
この相談の記録用に、CASE.md へ追記するエントリを Markdown のコードブロックで出して。
書式は次のとおり。実際の相談内容だけに基づき、推測で埋めない。

---

## <今日の日付 YYYY-MM-DD> [チャット] <この相談の要約>

### やったこと
（決まったこと・作ったもの。無ければ相談内容の要点）

### 判断
（何を選び、なぜか。見送った案も残す）

### 未決事項
（次回に送ったもの。無ければ「なし」）
```

出てきたエントリをコピーし、次に Code を開いたときにこう頼む。

```
<slug> の CASE.md にこのエントリを追記して: （貼り付け）
```

案件がまだ無ければ slug の代わりに案件の内容を言えば、Code 側が新規に作る。

## Cowork の場合

Cowork はファイルを書けるので、折り返しは不要。セッションの終わりに次を頼む。

```
.claude/commands/done.md を読んで、その手順どおりに記録して。案件は <slug>。
モードは [Cowork] と書く。
```

hook は効かないため、打ち忘れても次回通知は出ない点だけ注意。

## 別リポやリポ外で開いた Code の場合

ユーザー共通コマンド `/writeback <slug>` を打つ（`templates/writeback.md` を `~/.claude/commands/` に置いたもの）。
`~/agent-casebook` を絶対パスで更新するので、作業中のディレクトリがどこでも使える。
`/done` との違いは次の 2 点。

- エントリに `作業場所:` の行が付く（どのリポ / ディレクトリで作業したかを残す）
- コミットはその案件のファイルだけ（`cases/<slug>` と `INDEX.md`）。作業中のリポには何も書かない

Cowork を agent-casebook 以外のフォルダで開いているときも、このファイルを読ませれば同じ手順で書き戻せる。

```
~/.claude/commands/writeback.md を読んで、その手順どおりに記録して。案件は <slug>。
モードは [Cowork] と書く。
```
